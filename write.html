日記やノートをブラウザで書いて、そのまま公開できます。スマホからもOKです。

⚙ 初期設定(最初の1回だけ)
GitHubに保存するための「合言葉(トークン)」を入れます。トークンはこの端末のブラウザにだけ保存され、サイトには公開されません。
  1. トークン作成ページ を開く
  2. Token name は自由(例:study-site)、Expiration は好きな期間
  3. Repository access は Only select repositories → このサイトのリポジトリだけ選ぶ
  4. Permissions → Repository permissions → Contents を Read and write にする
  5. Generate token を押して、表示された文字列をコピーし、下に貼る
※トークンは他人に見せないでください。共有パソコンでは使わないでください。
書き方: ## 見出し / **太字** / - リスト / > 引用 / [文字](URL) / コードは ``` で囲む。画像はボタンで追加すると本文に入ります。
