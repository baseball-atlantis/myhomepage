管理画面

日記・ノート・資料(ファイル)・作品の追加と、サイト設定の変更を、すべてこの画面でできます。本人確認(GitHubトークン)が済むと編集画面が表示されます。

🔐 本人確認・初期設定
GitHubに保存するための「合言葉(トークン)」を入れます。トークンはこの端末のブラウザにだけ保存され、サイトには公開されません。
  1. トークン作成ページ を開く
  2. Token name は自由(例:study-site)、Expiration は好きな期間
  3. Repository access は Only select repositories → このサイトのリポジトリだけ選ぶ
  4. Permissions → Repository permissions → Contents を Read and write にする
  5. Generate token を押して、表示された文字列をコピーし、下に貼る
※トークンは他人に見せないでください。共有パソコンでは使わないでください。
本文(文字を選んでから、ボタンで装飾できます)
ボタンで入る記号をそのまま手で書いてもOKです。例: [color=#ff6b6b]赤い文字[/color] / [size=large]大きい文字[/size] / 右寄せは行だけの [right] と [/right] で段落をはさむ。画像の大きさは ![](img/xxx.jpg){w=50}(幅50%)。装飾は段落をまたげません。
トップページの文章を変更します。保存すると、公開ページに反映されます(1〜2分)。
使い方: GoatCounter(無料)に登録 → 決めた「Code」をここに入力。 さらに GoatCounter の Settings で 「Allow adding visitor counts on your website」 にチェックを入れて保存してください。
