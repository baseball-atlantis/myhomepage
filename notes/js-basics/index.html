JavaScript入門メモ

変数・関数・配列の基本を、自分の言葉でまとめたメモ。(これはサンプルのノートです)

変数

値に名前を付けて持っておく入れ物。let は後から変更できて、const は変更できません。

const name = "太郎";
let count = 0;
count = count + 1;

関数

処理をひとまとめにして、名前を付けたもの。何度でも呼び出せます。

function greet(name) {
  return "こんにちは、" + name + "さん";
}
greet("太郎");

配列

  • 複数の値を順番に並べて持てる
  • 番号(インデックス)は 0から 始まる
  • push で末尾に追加できる
ポイント:最初は全部覚えようとせず、手を動かして慣れるのが近道。
